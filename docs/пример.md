Результатом дипломного проектирования является разработанный
электронный помощник преподавателя для автоматизации проверки лабораторных
работ по предмету «Защита компьютерной информации».
Программный продукт позволяет пользователю авторизацию, заполнение
форм для добавления данных, редактирование и удаление данных, поиск и
сортировку информации. Основная задача, заключавшаяся в разработке надежного
и удобного в использовании помщника преподавателя для эффективной проверки
дабораторных работ, была успешно выполнена. Все ключевые функции были
реализованы, а интерфейс интернет-ресурса был разработан таким образом, чтобы
быть интуитивно понятным для пользователей.
В качестве инструментов разработки для данного программного продукта
были использованы: HTML 5, CSS 3, JavaScript, PHP 7.4, Microsoft Visual Studio
Code, MySQL 8.0, PhpMyAdmin 5.2.0.

В полной мере были реализованы требования, предъявляемые к интернет-
ресурсу, такие как:

- отсутствие рекламы;
- адаптивная верстка;
- должна сохраняться единая стилистика интернет-ресурса, вкладки
должны быть выполнены в едином дизайне;
- информация должна соответствовать тематике данной концепции;
- информация должна быть упорядочена по тематическим вкладкам;
- пользователь должен иметь возможность просматривать вкладки сайта,
заполнять формы, просматривать данные;
- вход должнен располагаться на главной странице на форме, где
пользователь регистрационный ключ, после авторизации пользователь попадает в
конкретную панель с соответствующими правами доступа к базе данных;
- преподаватель должен иметь возможность добавления учащихся;
- преподаватель должен иметь возможность редактирования данных
учащихся;
- учащийся должен иметь доступ к просмотру теории и выполнению
заданий.
Интернет-ресурс полностью отлажен и проверен на предмет выявления
видимых и скрытых ошибок.
При разработке программного продукта соблюдались требования
безопасности труда, электробезопасности, пожарной безопасности и
производственной санитарии.
